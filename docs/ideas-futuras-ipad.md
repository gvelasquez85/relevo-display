# Ideas futuras para reutilizar el iPad

Registradas por German el 24 de octubre de 2026. Son ideas para investigar después, no funciones confirmadas ni alcance de implementación actual.

Prioridad vigente: iPad2 con iOS7 como monitor Windows11 usando YamDisplay; validar resolución4:3, cursor, estabilidad/UAC y facilidad de uso, después touch. El iPad vuelve a estar conectado al Mac para futuras pruebas del protocolo; disponibilidad informada por el usuario, no comprobación técnica de esta anotación.

- Cámaras frontal/trasera del iPad como webcam para Windows. Investigar captura en cliente iOS, transporte, latencia y exposición como cámara en Windows. No se ha identificado este canal en el protocolo actual de Yam.
- Altavoces del iPad como salida de audio de Windows. Investigar cliente receptor, transporte/sincronización y dispositivo de audio virtual Windows. Sin soporte implementado ni confirmado en Yam.
- Audio de Windows hacia auriculares Bluetooth emparejados con el iPad, por ejemplo AirPods. Investigar primero compatibilidad real del accesorio con iOS7/iPad2 y enrutamiento de audio permitido por iOS. No asumir acceso general al adaptador Bluetooth desde Windows.
- Usar otras capacidades Bluetooth del iPad. Idea abierta; definir uso concreto y comprobar APIs/perfiles antes de prometer funciones.
- Iniciar o manejar apps del iPad desde Windows. Aclarar si significa abrir nuestra propia app, abrir apps concretas mediante enlaces admitidos o controlar aplicaciones ajenas. Son capacidades distintas; no asumir que el USB o nuestro cliente permiten control arbitrario de iOS.

Cada idea requiere una prueba de viabilidad independiente, en especial por las restricciones y recursos de iOS7. No sustituye el objetivo actual ni autoriza modificar el iPad, instalar software o interrumpir Yam para estas ideas.
