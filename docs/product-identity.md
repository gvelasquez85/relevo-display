# Relevo Display

Nombre elegido por German el24deoctubrede2026. Idea: dar una segunda vida útil a tabletas antiguas como pantallas y controles para ordenadores actuales. El nombre no está validado como marca comercial ni se registró dominio.

Desde0.6: móduloGo relevo, comando cmd/relevo, ventanaRelevo Display, ejecutableRelevo-Windows.exe, ZIPRelevo-Windows-0.6.0.zip, configuraciónRelevoDisplay. Los ajustes previos se migran sólo si falta la configuración nueva; no se borra el original.

Compatibilidad transitoria: todavía se necesita la app YamDisplay instalada en el iPad. RelevoDisplay no incluye aún un cliente iOSpropio. Se conservan identificadores técnicos previos donde alterarlos podría romper compatibilidad o seguridad entre versiones: hardwareID del saludo, mutex del adaptadorMTTVDD, respaldo de configuración y ruta antigua de migración. Se mantienen las evidencias/historial originales en análisis; no se reescribe procedencia ni licencias. Las referencias a terceros son descripciones de compatibilidad, no la marca del producto.

JPEG sigue siendo códec de la versión0.6. H264 es el candidato seleccionado para siguienteprototipo y requiere validación de empaquetado/captura/encoder/receptor, en especial sobre iOS7. Ver codec-evaluation-2026-10-24.md.
